# WA Boost

WA Boost by WA Boost.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/69620142205c5c3f999dffa5/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **WA Boost** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/69620142205c5c3f999dffa5/releases/latest) and reinstall.
